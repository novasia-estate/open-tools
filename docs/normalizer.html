Run the example to see the result.
Auto-detect reads a single separator followed by exactly three digits as a thousands separator: “1,500” becomes 1500. For decimal 1.500 or 1,500, select the number format explicitly. Conversion factors: 1 ft² = 0.09290304 m²; 1 rai = 1600 m²; 1 square wah = 4 m². Use this for data preparation, not title verification or currency conversion.
